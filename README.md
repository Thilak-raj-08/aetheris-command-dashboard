# Aetheris Command — Global Treasury, Supply Chain & Cloud Telemetry Dashboard

A multi-page institutional command center and operational analytics dashboard built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and **Framer Motion**.

## Multi-Page Architecture
- **`/` (Command Overview)**: Real-time net liquidity, multi-currency switcher (`USD`, `EUR`, `GBP`, `LKR`), interactive cashflow area/bar chart, live settlement feed, and NOC visual telemetry.
- **`/revenue` (Treasury & Ledger)**: Searchable institutional wire ledger, clearing status filters, interactive **Initiate Wire Transfer** modal, and CSV audit export.
- **`/logistics` (Fleet & Supply Chain)**: Global maritime & air freight corridors, container manifest telemetry (temperature, customs status, ETA), and route inspection.
- **`/infrastructure` (Cloud Nodes & SLA)**: 6-region infrastructure health matrix, P99 latency telemetry, and interactive traffic failover simulation.
- **`/settings` (RBAC & Security Audit)**: Role-based access control directory, API key lifecycle management, and immutable compliance audit trail.
